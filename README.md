# Pepe Nero — sito web

Sito della Pizzeria Pepe Nero (Enna). Next.js + Tailwind, animazioni con Motion e Lenis.

## Dove si cambiano i contenuti

- `lib/site.ts` — indirizzo, telefoni, orari, social, link Glovo/Deliveroo, P.IVA
- `lib/menu.ts` — tutte le pizze e i prezzi

## Sviluppo

```bash
npm install
npm run dev
```
